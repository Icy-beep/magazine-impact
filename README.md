# Magazine Impact

Клиентский мод для **SPT 4.1.6**: звук удара магазина при столкновении с полом,
стеной и другими поверхностями после выброса или быстрой перезарядки.

**Сохранённая рабочая версия: 0.2.1.** Пользователь подтвердил работу в игре
20 октября 2026 года. Совместимость с другими версиями SPT не проверена.
Репозиторий подготовлен для личного хранения и возвращения к игре.

## Установка сохранённой версии

1. Скачай `releases/MagazineImpact-0.2.1-SPT-4.1.6.zip` через кнопку Download raw.
2. Закрой игру. При обновлении удали старую папку
   `BepInEx/plugins/MagazineImpact` целиком: оставшиеся WAV иначе попадут в набор.
3. Распакуй папку `BepInEx` из архива в корень SPT.
4. В F12 проверь `Sound / Use surface sounds = true`. Конфиг можно оставить.

Готовая папка `BepInEx` в этом репозитории содержит тот же плагин и звуки.
SHA256 исходного рабочего архива записан в `releases/SHA256SUMS.txt`.
Архив сохранён без изменения после проверки пользователем. В его старой
инструкции/BuildInfo ещё указано, что проверка 0.2.1 в рейде предстоит;
эта запись сделана до успешного теста, актуальный статус указан здесь.

## Звуки

| Поверхности | Используемая запись |
| --- | --- |
| Wood, WoodThin, WoodThick | Два S&W Magazine Drop |
| Soil, Gravel | G3 Mag Drop |
| Grass | Выбранная пользовательская запись травы |
| Concrete, Asphalt, Slate, Tile, Glass, WholeGlass | Выбранная пользовательская запись бетона |
| Metal, MetalThin, GarbageMetal, Garbage | G3 Mag Drop |
| Puddle, Swamp, Snow | Та же запись травы |
| Plastic | Одобренная запись удара об линолеум |
| Неизвестный материал / отсутствующая или испорченная папка | Отладочный impact.wav |

Все 20 известных типов покрыты записями. Назначения воде, снегу, металлу
и стеклу условные: отдельных записей этих поверхностей нет. Громкость
выравнивалась постоянным усилением по максимальному участку 50 мс;
пиковый уровень ограничен для предотвращения перегруза. Тембр разных звуков
может влиять на субъективную громкость.

WAV загружаются один раз при запуске. Точный тип, например `sounds/MetalThin`,
имеет приоритет над семейством `sounds/metal`. После замены файлов перезапусти игру.

## Настройки и проверка

В F12 / Magazine Impact доступны включение, громкость, дистанция, порог
силы удара и тестовый выбор поверхности. `Play test sound 2D/3D` срабатывает
через секунду и автоматически выключается. При неполадках включи Debug logging
и проверь `BepInEx/LogOutput.log`.

По умолчанию: громкость 0.7, дистанция 22 м, минимум 0.45 м/с,
полная громкость при 3.5 м/с, интервал столкновений 0.10 с.
Выключение `Use surface sounds` специально включает общий отладочный звук.

## Сборка исходников

Нужны .NET SDK, поддерживающий netstandard2.1, и собственная установка SPT 4.1.6:

```powershell
dotnet build .\MagazineImpact.csproj -c Release -p:GamePath="D:\SPT"
```

Результат: `bin/Release/netstandard2.1/MagazineImpact.dll`.
Для проверки замени DLL в `BepInEx/plugins/MagazineImpact` своей установки;
звуки и сопроводительные файлы возьми из одноимённой папки репозитория.
Сборка проекта сама по себе не обновляет сохранённый архив в `releases`.
DLL игры и сторонних библиотек в репозиторий не включены: они берутся
из указанного GamePath. Не добавляй их в git.

## Как устроен код

- `MagazineImpact.cs`: подключение BepInEx/Harmony, обработка столкновений и настроек.
- `SurfaceResolver.cs` / `SurfacePolicy.cs`: определение материала и семейства.
- `SurfaceSoundBank.cs`: загрузка WAV и выбор варианта.
- `RuntimeClip.cs`: кеш PCM и восстановление Unity AudioClip после сброса аудио.
- `GameAudio.cs`: проигрывание через игровую аудиосистему.
- `ImpactPolicy.cs` / `Wav.cs`: сила удара, интервалы, чтение PCM16.
- `tests`: проверки логики и банков с имитацией Unity AudioClip.

Исходники разработаны с существенной помощью ИИ; пользователь подбирал,
записывал и проверял звуки и тестировал мод в игре.

## Ограничения

Окклюзия отключена: звук может быть слышен через стены. Звук не передаётся
в слуховую систему ботов. Отскоки физики озвучиваются отдельно, поэтому хвост
записи при некоторых столкновениях может восприниматься как повторный удар.
Fika и совместимость с другими модами на звук предметов отдельно не проверены.
